## 📖 About

A collection of hands-on networking laboratory exercises completed as part of my university coursework. This repository contains configurations, topologies, and Packet Tracer files designed to reinforce core networking concepts.

---

```
Networking/
```

## 🚀 How to Use

<div style="background-color:#fff3e0;border-left:4px solid #ff9800;padding:12px 16px;border-radius:4px;margin:8px 0">

<b>Step 1:</b> Open the <code>.pkt</code> files with <b>Cisco Packet Tracer</b> (version 8.x or later recommended)<br/>
<b>Step 2:</b> Review the lab instructions and topology<br/>
<b>Step 3:</b> Verify configurations using the provided device CLI outputs<br/>
<b>Step 4:</b> Test connectivity and validate the implemented concepts
